# PRD: 个人技术统计（增量功能）

> 项目：Calc24 | 类型：Brownfield 增量 | 作者：PM Agent (John)
> 日期：2026-05-17

---

## 1. 概述

为 Calc24 添加「个人技术统计」面板，让玩家能够查看自己的历史游戏数据、能力雷达图和成长趋势。当前排行榜只记录 Top 10 成绩，缺乏对玩家整体水平的全面画像。

### 不包含

- ❌ 后端/云端同步（纯本地 localStorage）
- ❌ 社交分享功能
- ❌ 多用户切换
- ❌ 对现有排行榜功能的修改

---

## 2. 用户故事

### US-1: 查看累计统计

**作为**一个 Calc24 玩家，
**我想要**看到我的累计游戏数据，
**以便**了解自己的整体游戏水平。

**验收标准：**
- Given 玩家打开统计面板
- When 页面加载完成
- Then 显示以下累计数据：
  - 总游戏局数
  - 总胜利局数
  - 胜率（%）
  - 总游戏时长
  - 连胜最高纪录

### US-2: 查看平均表现

**作为**一个 Calc24 玩家，
**我想要**看到我的平均表现指标，
**以便**了解自己的稳定性。

**验收标准：**
- Given 玩家至少完成 1 局游戏
- When 查看统计面板
- Then 显示：
  - 平均解题时间（秒）
  - 平均操作步数
  - 平均每局得分

### US-3: 查看能力雷达图

**作为**一个 Calc24 玩家，
**我想要**看到一个可视化的能力雷达图，
**以便**直观了解自己的强项和弱项。

**验收标准：**
- Given 玩家至少完成 5 局游戏
- When 查看统计面板
- Then 显示五维雷达图：
  - 速度（基于平均解题时间）
  - 精准（基于平均操作步数）
  - 耐力（基于连续游戏局数）
  - 稳定（基于成绩方差）
  - 直觉（基于首次操作正确率）
- Given 游戏局数不足 5 局
- When 查看雷达图
- Then 显示"再玩 N 局解锁能力分析"提示

### US-4: 查看近期趋势

**作为**一个 Calc24 玩家，
**我想要**看到最近的表现趋势，
**以便**知道自己是在进步还是退步。

**验收标准：**
- Given 玩家至少完成 3 局游戏
- When 查看统计面板
- Then 显示最近 20 局的趋势折线图：
  - X 轴：局数序号
  - Y 轴：得分 / 用时（可切换）
  - 标注平均线
- Given 游戏局数不足 3 局
- When 查看趋势图
- Then 显示"数据积累中..."占位

### US-5: 统计数据持久化

**作为**一个 Calc24 玩家，
**我想要**我的统计数据在刷新页面后仍然保留，
**以便**长期追踪我的进步。

**验收标准：**
- Given 玩家完成一局游戏
- When 游戏结束（胜利或超时）
- Then 自动将本局数据追加到 localStorage
- Given 玩家刷新页面
- When 打开统计面板
- Then 所有历史数据完整显示

## 3. 数据模型

### 3.1 单局记录（GameRecord）

```typescript
interface GameRecord {
  id: string              // 唯一 ID（时间戳）
  date: string            // ISO 日期 YYYY-MM-DD
  timestamp: number       // Unix 时间戳
  won: boolean            // 是否胜利
  timeUsed: number        // 用时（秒）
  moves: number           // 操作步数
  score: number           // 得分
  numbers: number[]       // 本局数字牌
}
```

### 3.2 聚合统计（PlayerStats）

```typescript
interface PlayerStats {
  totalGames: number
  totalWins: number
  winRate: number          // 0-100
  totalPlayTime: number    // 秒
  longestStreak: number    // 最长连胜
  currentStreak: number    // 当前连胜
  avgTime: number          // 平均用时
  avgMoves: number         // 平均步数
  avgScore: number         // 平均得分
}
```

### 3.3 存储 Key

| Key | 内容 | 格式 |
|-----|------|------|
| `calc24_gameRecords` | 所有单局记录 | `GameRecord[]` |
| `calc24_playerStats` | 聚合统计缓存 | `PlayerStats` |

## 4. UI 设计要求

### 4.1 入口

- 在主界面添加「📊 统计」按钮（与排行榜按钮并列）
- 点击后弹出统计面板（全屏 overlay，与排行榜面板风格一致）

### 4.2 面板布局

```
┌─────────────────────────────────┐
│  📊 个人统计          [关闭 ×]  │
├─────────────────────────────────┤
│  ┌───────┐ ┌───────┐ ┌───────┐ │
│  │总局数 │ │ 胜率  │ │连胜记录│ │
│  │  42   │ │ 78%   │ │  12   │ │
│  └───────┘ └───────┘ └───────┘ │
├─────────────────────────────────┤
│         🕸️ 能力雷达图           │
│        (Canvas/SVG 绘制)        │
├─────────────────────────────────┤
│         📈 近期趋势             │
│    [得分] [用时] 切换标签       │
│    ~~~~~~~~~~~~~~~~~~~~~~~~     │
│    (折线图，最近 20 局)         │
├─────────────────────────────────┤
│  平均用时: 28s | 平均步数: 12   │
│  总游戏时长: 2h 15m             │
└─────────────────────────────────┘
```

### 4.3 视觉规范

- 与现有 UI 风格保持一致（SCSS 变量复用）
- 雷达图和折线图用纯 SVG/Canvas 实现，不引入图表库
- 移动端优先，面板可滚动
- 数字动画：首次打开时数字从 0 滚动到实际值

---

## 5. 技术约束

| 约束 | 说明 |
|------|------|
| 无新依赖 | 图表用原生 SVG 或 Canvas 实现 |
| 向后兼容 | 不修改现有 `useLeaderboard` 和 `useGame` 的接口 |
| 存储隔离 | 使用独立的 localStorage key，不影响现有数据 |
| 性能 | 统计计算在打开面板时按需执行，不影响游戏帧率 |
| 数据上限 | 最多保留最近 500 局记录，超出时 FIFO 淘汰 |
